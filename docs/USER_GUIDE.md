# 使用指南

[English](USER_GUIDE.en.md) | 简体中文

编译烧录见 [FLASH.md](FLASH.md)，连不上先看 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。

> **WS128（1.28" 无触摸板）用户**：本指南的全部操作（导航、调亮度、蓝牙页）
> 都基于触摸手势；WS128 板没有触摸，固件以**纯显示模式**运行——开机、显示
> 仪表页、BLE 自动回连上次绑定的适配器都正常，但无法手动翻页。无触摸板可用
> **WiFi 取图**远程查看画面并通过**远程触摸**完整操作（开机自动开热点，见下方
> 「WiFi 取图」）。1.28" 的**触摸版**（WS128T）带完整电容触摸，本指南全部
> 操作原样可用。

## 首次开机

1. 上电先显示 **SKY GAUGE** splash（约 1.2 秒），随后进入**挡位 / 转速页**
2. 若 NVS 里已绑定 ELM327 适配器（此前配对过，或经 NVS 工具写入），开机自动回连，
   数据开始刷新；数据中断自愈重连，**上车通电即可，无需任何手动操作**
3. 未绑定时页面照常渲染，数值显示 **—**（断连语义）；绑定路径见下方「蓝牙页」

## 页面导航（16 页轮播）

主界面是**横向轮播**：**左右滑动**按顺序循环切换 16 个页面——

| # | 页面 | 内容 |
|---|------|------|
| 1 | GEAR（挡位 / 转速）| 56 段转速弧 + 大挡位 + 底部油温/油压摘要 |
| 2 | MANIFOLD（增压 / 真空）| 270° 压力弧 + 细指针，量程 −1..3 bar |
| 3 | COOLANT（冷却液温度）| 纵向温度柱（60–120°C，110°C 起红区）+ 状态字 |
| 4 | OIL TEMPERATURE | 270° 油温弧 + 主读数（40–140°C）|
| 5 | OIL PRESSURE | 左侧偏心机械表 + 右侧读数（0–6 bar）|
| 6 | POWERTRAIN（三项综合）| 增压横条 + 油温/油压双读数 |
| 7 | ENGINE VITALS（多项综合）| 四角油压/油温/电压/水温 + TPS / B.P 切换区（点按切换）|
| 8 | TYRE MONITOR | 车身俯视线稿 + 四轮胎压（≤0.5 bar 红色低压告警 / ≥3.4 bar 琥珀高压，页脚摘要）|
| 9 | SPEED | 路景透视动效（车速越快掠过越快，停车即停）+ 巡航状态 |
| 10 | G-FORCE | 1g/2g 同心圆 + 当前 G 力点（超过 1.0 g 显示虚线阈值圈、点变琥珀）|
| 11 | DRIVER PULSE | 心率与趋势（数据源未接入，显示 NO SENSOR 态）|
| 12 | PRESSURE / ANALOG | 41 刻度机械增压表 |
| 13 | NOW PLAYING | 媒体页（数据源未接入，显示断连态）|
| 14 | ILLUMINATION | 日间 / 夜间亮度记忆与调节 |
| 15 | CONNECTIONS | 蓝牙适配器状态、绑定管理 |
| 16 | PAIR DEVICE | 配对码展示 |

## 日间 / 夜间与亮度（ILLUMINATION 页）

- **DAY / NIGHT 两档亮度**分别记忆（默认 85% / 35%），点 **−/+** 每次 ±5，
  范围 10–100%，越界的键自动置灰；调节即时生效并写入 NVS
- 底部按钮在 **DAY ACTIVE / NIGHT ACTIVE** 间切换；夜间模式下所有主文字
  变为夜间琥珀色（设计语义：夜间接管），背光按夜间档输出

## 蓝牙连接（CONNECTIONS / PAIR DEVICE 页)

- 顶部 chip 显示适配器状态：**DEVICE CONNECTED**（绿，已绑定且已连接）/
  **CONNECTION LOST**（琥珀，已绑定未连接，页脚提示 SAVED PAIRING RETAINED）/
  **NO DEVICE**（未绑定）
- **FORGET ALL** 清除适配器绑定（名称 + MAC）——点按后弹**确认对话框**，
  选 **CLEAR** 才真正清除，**CANCEL** 返回；**PAIR** 进入配对码页——
  配对码由设备 MAC 派生，在配套 App 中输入完成绑定
- 本页 **BACK** 返回挡位 / 转速页（页 1）
- **DISCOVERABLE / REMOTE KEY** 两个开关当前为 UI 预留（固件侧能力待接入）

## 数据与断连

- 所有数据经统一通道直读 OBD 数据缓存（BLE / ESP-NOW 双源，线程安全）
- **通道报警**：越限时页脚显示原因摘要（多项为「首条 +N」），critical 级另有
  表盘外缘双红弧、相关读数变红。阈值：水温 ≥110°C、油温 ≥130°C（红色
  告警，即表盘红区 130–140）、油压 <1.0 bar（红色告警）、增压 ≥2.4 bar、转速 ≥6800（换挡提示）/ ≥7000（红色告警，即表盘红区
  7000–8000，进红区即报）、电压 ≤10.8 / ≥16.4 V、胎压 ≤0.5（红色）/ ≥3.4 bar、
  G 值 >1.0 g（虚线阈值圈 + 页脚提醒）
- 断连（适配器断开且无从表数据）时：数值显示 **—**，动态指示隐藏，报警摘要
  抑制，表盘底部显示琥珀色 **NO SIGNAL**（心率页为 NO SENSOR）；恢复后自动续显

## 已知裁剪（相对旧版 UI）

旧版的设置页、OBD 协议选择、主题系统、告警阈值页、自定义仪表页、
OTA 升级入口页已随 JDM UI 重写移除：车型 / 轮询等沿用 NVS 既有值，
OTA 的 HTTP 服务端仍保留但暂无界面入口（见 [FLASH.md](FLASH.md#app-ota-升级双槽回滚)）。
这些功能后续按 JDM 设计语言逐步补回。

## WiFi 取图（远程看仪表 / 截图）

固件可以把当前画面通过 WiFi 输出，仪表本身照常工作（BLE/ESP-NOW 不中断）：

1. **WS128 等无触摸板**：开机自动开热点（`OBD_SCREENSHOT_AUTO_START`，默认在
   ws128 构建中打开）；触摸板构建可在 menuconfig 打开同名选项
2. 手机/电脑加入热点 `OBD-Gauge-View-XXXX`（密码 `88888888`）
3. 浏览器打开 `http://192.168.4.1:8080/`：实时画面（约 12fps MJPEG）+
   「下载当前帧 JPG」「下载精确色 BMP」按钮；也可直接 `curl -o shot.bmp
   http://192.168.4.1:8080/screenshot.bmp`

**远程触摸**（`OBD_REMOTE_TOUCH`，ws128 构建默认开）：控制页画面可直接
**滑动/点按**操作仪表——翻页、调亮度、蓝牙页全部手势与真触摸一致。

加入热点期间该设备没有外网，看完切回原 WiFi 即可。端点细节见
[APP_PROTOCOL.md](APP_PROTOCOL.md)。

## 外接传感器（可选）

| 传感器 | 接法 | 说明 |
|--------|------|------|
| RS485 刹车温度 | GPIO13（TX）/ GPIO12（RX），9600 baud，Modbus RTU | 数据并入统一通道 |
| ADS1115 油压 | I2C，仅 V1 微雪板 | Supra A90 / BMW E 等车型可由 OBD 直读油压 DID 替代 |

排障分别见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md) 对应章节。
