# 使用指南

[English](USER_GUIDE.en.md) | 简体中文

编译烧录见 [FLASH.md](FLASH.md)，连不上先看 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。

> **WS128（1.28" 无触摸板）用户**：本指南的全部操作（导航、设置、BLE 扫描）都基于
> 触摸手势；WS128 板没有触摸，固件以**纯显示模式**运行——开机、显示仪表页、
> BLE 自动回连上次绑定的适配器都正常，但无法手动导航/进设置（页面停在默认首页，
> 沿用之前在触摸板上配好的 NVS 设置）。无触摸板可用 **WiFi 取图**远程查看
> 画面并通过**远程触摸**完整操作（开机自动开热点，见下方「WiFi 取图」）。构建方式见
> [DEVELOPMENT.md](DEVELOPMENT.md#适配新开发板)。

## 首次开机

1. 上电后先显示 Sky Gauge Logo，随后按设置的开机模式进入（默认 RACE 动画，可关）
2. 第一次使用先进 **设置页**（MENU → SETTINGS）：**VEHICLE** 滚轮选你的
   车型（立即生效，不用重启）
3. 回 **MENU → BLE SCAN**，扫描并选中你的 ELM327 BLE 适配器
4. 连接成功后仪表自动初始化（自动协议检测见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md#协议自动检测)），数据开始刷新

之后每次上电仪表会自动回连上次的适配器（记忆 BLE 名称 + MAC），数据中断也会自愈重连，
正常情况下**上车通电即可，无需任何手动操作**。

## 页面导航（动态仪表页）

主界面是**可自定义的仪表页分页**：左右滑动在平铺间切换——

```
   MENU → [仪表页 1..N，可增删改] → ADD
```

- **MENU 平铺**：车型名 + 三个入口按钮 —— **BLE SCAN**（连接 OBD 适配器；
  从表角色时兼作 FIND MASTER 扫描）、**SETTINGS**（设置页）、**INFO / OTA**
  （版本页：build tag、连接状态、OTA 按钮与隐藏入口）
- **仪表页**（初始 6 页，按你升级前的 TEMP/INFO/CHART/NEEDLE 配置自动迁移
  生成，外观与原来一致）：
  - **METRIC 页**：1–6 个数据卡（水温/油温/进气温/转速/车速/油压/G 力/
    胎压等 18 个通道任选）
  - **GEAR 页**：大字挡位（含 R/N，0x141 直读优先，回退转速比值推算）+ RPM 弧
  - **G-FORCE 页**：G 力点图（纵向/横向，0.01g）
- **ADD 平铺**：点 "+" 追加一个新仪表页（上限 8 页），默认单槽 RPM

**长按任意仪表页 → 编辑态**（翻页锁定，出现三区蒙层）：

- **EDIT**（左上）→ 配置页：TYPE（METRIC / GEAR / G-FORCE）；METRIC 页
  可调 SLOTS（1–6）与每个槽位的 CHANNEL（18 通道滚轮），改动即时保存
- **DELETE**（右上）→ 删除该页（至少保留一页），回到 MENU
- **BACK**（底部）→ 退出编辑态

左右滑返回 / 退出配置页；数据超时或蓝牙断开时仪表页显示 **NO SIGNAL**。

**版本页**（经 MENU → INFO / OTA 进入）：上滑 → BLE SCAN，下滑 → 设置页，
OTA 按钮 → OTA 升级模式（见 [FLASH.md](FLASH.md#app-ota-升级双槽回滚)）。

**隐藏入口**（不变）：

- **Logo 页双击** → OBD 协议选择滚轮（**长按 2 秒**保存并重启；协议 0 = 自动检测）
- **版本页快速连点 10 次** → 展厅演示模式（扫表动画）

> 旧版静态轮播（GEAR→RPM→…→版本页 环）已被动态页取代；其数据映射在首次
> 启动时迁移为初始仪表页。加载了带页面的运行时主题时，开机仍进入主题表盘页
> （主题页 ↔ 版本页 互滑循环）。

## 设置页

| 设置项 | 说明 |
|--------|------|
| VEHICLE | 17 个车型配置，切换立即生效（影响挡位识别、油温策略、协议锁定等）|
| THEME | 编译期内置主题（default / amber / ocean 及社区主题），选中后**自动重启生效** |
| 亮度 | 10–100% |
| OBD POLL | 轮询档位 NORMAL / FAST / TURBO（默认间隔 30 / 15 / 5ms，下一轮询周期即生效，无需重启）。车型已锁定轮询间隔的（如 ZN/C6 CAN、MX-5）不受影响；TURBO 档对廉价克隆适配器可能过快，出现数据不稳时退回 NORMAL |
| RACECHRONO | ON=完整 BLE 服务（RaceChrono + 配对 + OTA）；OFF=最小模式（仅 Info + OTA 服务，不广播），省内存 |
| 下滑 → MULTI-GAUGE | 三连表角色设置（见下）|

所有设置存 NVS 断电不丢。里程 / 行程统计只在本轮通电内累计，重启清零。

## 三连表（ESP-NOW 联动）

一块 ELM327 适配器只允许一个蓝牙客户端，所以多块表采用**一主多从**：

- **主表（MASTER）**：保持 BLE + ELM327 连接读数据，通过 ESP-NOW 广播解析后的数据
- **从表（SLAVE）**：只收广播渲染，零额外 OBD 负载
- **独立模式（默认）**：不启用 ESP-NOW

三块板烧同一份固件，角色在 **设置页 → 下滑 → MULTI-GAUGE** 里选（重启生效）。

**配对流程**（真蓝牙配对，不是盲收广播）：

1. 主表设为 MASTER，开始广播 `SkyGauge-XXYY`（XXYY 为设备后缀，多车同场不冲突）
2. 从表设为 SLAVE；未配对过时开机会直接进入 **FIND MASTER** 扫描页
3. 在列表里选中要跟随的主表，完成绑定（记忆主表 MAC，之后每次开机自动跟随）

三连表还支持**联动转速报警**：超阈值时三块表按表位依次亮起再全体闪烁
（RPM 报警页里可开关 Linked 模式），以及开机 "RACE / AS / ONE" 同步动画。

## 开机动画

设置三种模式（NVS `intro_enable`）：

| 模式 | 效果 |
|------|------|
| OFF | 跳过动画直接进仪表 |
| RACE | 内置 "RACE AS ONE" 动画（三连表同步）|
| VIDEO | 播放 `bootmedia` 分区里的自制动画（用手机 App 上传，见 [FLASH.md](FLASH.md#app-ota-升级双槽回滚)）|

自制动画要求：360×360 画布、1:1 比例、注意圆屏四角裁切；设备端更新是事务式的，
上传中断不会破坏现有动画。

## 手机 App 升级

配套 App（不随本仓库分发）支持三种推送，都需要先在仪表
**版本页 → OTA 按钮** 进入 OTA 模式：

- **固件升级**：BLE 握手 → WiFi 热点（`OBD-Gauge-OTA-XXXX`，密码 `obd2024`）高速传输，
  写入备用 OTA 槽；新固件启动 15 秒自检通过才标记有效，失败自动回滚
- **开机动画**：App 内裁切视频、编码后上传
- **主题包**：推送运行时主题到 theme_0 分区（见 [THEMES.md](THEMES.md)）

设备会通过 BLE 只读清单服务（`0x1FFA`）暴露硬件 / 构建信息，App 刷写前自动做兼容校验，
硬件不匹配会拒绝刷写。协议细节见 [APP_PROTOCOL.md](APP_PROTOCOL.md)。

## WiFi 取图（远程看仪表 / 截图）

固件可以把当前画面通过 WiFi 输出，仪表本身照常工作（BLE/ESP-NOW 不中断）：

1. 触摸板：进 **MENU → INFO/OTA → OTA 按钮**（OTA 模式页热点开启时即可取图）；
   **WS128 等无触摸板**：开机自动开热点（`OBD_SCREENSHOT_AUTO_START`，默认在
   ws128 构建中打开）
2. 手机/电脑加入热点（OTA 模式为 `OBD-Gauge-OTA-XXXX`，自动热点为
   `OBD-Gauge-View-XXXX`，密码均 `88888888`）
3. 浏览器打开 `http://192.168.4.1:8080/`：实时画面（约 12fps MJPEG）+
   「下载当前帧 JPG」「下载精确色 BMP」按钮；也可直接 `curl -o shot.bmp
   http://192.168.4.1:8080/screenshot.bmp`

**远程触摸**（`OBD_REMOTE_TOUCH`，ws128 构建默认开）：控制页画面可直接
**滑动/点按/长按**操作仪表——翻页、进设置、长按编辑全部手势与真触摸一致；
画面下方的「远程触摸」勾选框可临时关闭（关闭后页面可正常滚动）。

加入热点期间该设备没有外网，看完切回原 WiFi 即可。端点细节见
[APP_PROTOCOL.md](APP_PROTOCOL.md)。

## 外接传感器（可选）

| 传感器 | 接法 | 说明 |
|--------|------|------|
| RS485 刹车温度 | GPIO13（TX）/ GPIO12（RX），9600 baud，Modbus RTU | 数据并入 CHART 曲线页；刹车温度报警 30 秒节流一次 |
| ADS1115 油压 | I2C，仅 V1 微雪板 | Supra A90 / BMW E 等车型可由 OBD 直读油压 DID 替代 |

排障分别见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md) 对应章节。
