# Components & foundations

[English](DESIGN_SYSTEM.en.md) | 简体中文

这套规范以当前仓库原型为事实源，沿用早期 Figma 的 Foundations、Readout、Action、Gauge Shell 思路，补充最近确认的控件与圆屏规则。交互示例在 [components.html](components.html)；浏览器入口为 <http://127.0.0.1:8769/components.html>。

## 分层与事实源

- `foundations.js`：颜色用途、字体角色、字号、圆屏几何、间距、描边与点击尺寸。
- `foundations.css` / `foundations.json`：从基础定义生成的浏览器样式变量和可读数据；不要手改。
- `components.js` / `components.css`：共用 SVG 组件、属性、状态和反馈。
- `scenarios.js`：每页状态场景、示例读数、报警原因与优先级、独立心率数据状态及可选提醒限值。
- `nc-gauges.js`：17 个页面的组合与交互；页面坐标负责各自构图。
- `art.js`：基础矢量图形，颜色与标签字体通过语义绑定引用基础定义。
- `components.html` / `catalog.js`：调用实际共享组件的交互规范页，帮助检查尺寸与状态。

共同基础和控件改在对应共享层；特有刻度、坐标图、车辆线稿与分区构图保留在页面和图形层。

## 基础规则

### 颜色

- `text` / `muted`：主要读数与辅助文字。
- `amber`：选中、强调和当前项，配合下划线、描边或文字。
- `red`：报警；Readout 的 warning 状态始终使用报警色。
- `green` / `blue`：正常状态与连接信息。
- `night`：夜间读数颜色；日夜亮度属于独立交互状态。
- `face` / `panel` / `line`：表盘底色、控件表面和结构线；外页面板使用独立的 viewer 角色。

不要仅靠颜色表达状态。报警需要读数或原因文案；不添加叹号前缀、叹号后缀或叹号图标。当前选择需要标记，断连使用 `—` 和状态信息。

### 报警与提醒覆盖

报警是页面设计的一部分，验收既检查状态视觉，也检查适用场景是否齐全。以下场景均已加入原型；阈值和读数使用演示配置，具体车辆数据接入另行处理。

- 01：换挡提示、转速超限，以及辅助油温高、油压低；换挡建议使用琥珀提示，与红色故障报警区分。
- 02 / 12：压力超限；03 / 04：温度高；05：油压低。02 与 12 表达相同压力异常时使用一致的状态语义。
- 06：增压、油温、油压分别可报警；07：油压、油温、水温、电压高 / 低、增压分别可报警。TPS / B.P 显示操作输入，其数值高本身不构成故障。
- 08：任一轮胎压低 / 高、胎温高；通过轮位、读数和原因共同定位异常。
- 09：用户设置的超速提醒，可选启用；10：G 值限值提示可选启用，默认呈现运动数据；11：用户设置范围外的心率高 / 低提醒，独立提供无数据状态，文案不作健康诊断。
- 13 / 15 / 16 / 17：媒体不可用、连接丢失、配对失败等系统状态；14 亮度设置无需数值阈值报警。

异常读数和对应指针 / 有效弧 / 分区同步强调，并显示简短原因。综合页标明具体异常项，正常项保留原有层级；多项异常按严重度排序，给每一项保留可辨识标记。危急状态使用半径 330 的两段外缘细红弧，保持主读数清晰；普通异常局部强调，提示使用琥珀色。不使用整屏闪烁。

无数据优先于有效数值的越限提示，不能同时显示 `—` 与有效报警原因。预览区“状态场景”支持逐项选择，每页保留独立选择；06 / 07 / 08 提供多项异常样例，摘要显示最高优先级原因与其余项数量，各异常分区保留标记。“异常轮位”支持 FL / FR / RL / RR。09 / 10 / 11 的限值输入可调整演示设置。

系统状态有独立恢复方式：媒体不可用时禁用三个播放控件；连接丢失保留已存配对；配对失败提供重试，配对码过期提供新码。心率断连显示 `NO SENSOR` 和 `—`，不会受车辆数据开关影响。

### 字体与尺寸

数字使用 Barlow Condensed，标签、单位和状态使用 IBM Plex Mono；中文歌词使用系统字体。

- `hero`：180 母版像素，对应 90px 显示。
- `eccentric`：144，对应 72px。
- `analog`：96，对应 48px。
- `compact`：76，对应 38px。
- `mediaTitle`：60，对应 30px，专用于音乐页歌曲名称。
- `title` / `label` / `support` / `small`：28 / 26 / 24 / 22，对应 14 / 13 / 12 / 11px。

字号和字体角色定义在同一个基础文件中。优先使用现有角色，新增角色时说明用途；不要按页面复制一套配色和字号。

### 圆屏和间距

- 母版为 720×720，显示参考为 360×360，圆心为 (360,360)。坐标、尺寸和半径均写母版值。
- 内容检查边界半径为 342；按钮点击区域的四个角须位于半径 318 的交互安全区内。
- 点击区域至少为 88×88 母版像素，即 44×44px 显示。组件会拒绝过小、非有限数值及越界区域。
- 共享间距角色为 8 / 16 / 24 / 32 母版像素。独立仪表与读数分区建议至少留出 32 母版像素，即 16px 显示间距。
- 组件区域不能覆盖其他数据区。按 360 原尺寸检查数字最大位数、长文案、报警和断连状态。
- 机械表的指针位于印刷式表盘文字之上，可以扫过名称、单位或刻度；这种层叠不单独判定为布局缺陷。独立数字读数、状态提示和按钮仍须保持清晰，不能被长期遮挡。02 当前细指针与底层名称的层叠予以保留。

## 组件与属性

### Readout

属性包括 `x`、`y`、`label`、`value`、`unit`、`size`、`state`，以及正常状态的可选强调色 `color`。

- `size`：`primary`、`compact`、`eccentric`、`analog`。
- `state`：`normal`、`warning`、`disconnected`。
- 标签、数字和单位共用中心轴；不同尺寸具有固定的纵向间距。
- `warning` 强制使用报警色；`disconnected` 显示 `—`，不显示传入的有效值。

```js
const U = NC_COMPONENTS;
U.readout({
  x: 200, y: 220, label: 'OIL TEMP', value: '104', unit: '°C',
  size: 'primary', state: 'normal'
});
```

Figma 的 `Size / State` 和 `Label / Value / Unit` 对应这里的尺寸、状态与文本属性。`metric(...)` 适配入口支持最后一个 `state` 参数；无数据状态优先于报警。

### Road Scene 与动效

09 使用 `roadScene` 绘制低对比的树木和建筑，`roadProjection` 负责透视位置、缩放和淡入淡出，`roadMotion` 将车速换算为位移与出现频率。基础参数来自 `foundations.js` 的 `road`，母版坐标和圆屏内容规则不变。景物配色使用 `road.colors`：树木为低饱和灰绿色描边与深绿填色，建筑保留灰色轮廓，仅少量窗户使用暗暖色。颜色随透视透明度淡入淡出，车速和报警仍保持主要视觉层级。

两侧物体间距示意为 30m，每侧 5 个。出现频率与车速成正比：40 km/h 约为每侧 0.37 次/秒，120 km/h 约为每侧 1.11 次/秒。物体从远处较小、较淡的位置出现，向近处放大后从圆屏边缘消失；保持在主读数和巡航状态两侧。

浏览器用连续累计位移驱动动画；调速或重绘不将进度重置。停车、车辆断连、离开 09 页、页面不可见或系统偏好减少动画时停止，恢复后续接原位置，不补跑隐藏时段。图库及 SVG / PNG 导出固定静态帧，动效在交互网页中展示。

预览车速滑块提供 0–220 km/h 示例输入。超速提醒启用后只在当前速度超过所设限值时强调；切换场景会恢复相应示例速度。

### Alert 与动态图形

`alertField` 为数据区标明异常项与语义状态；`alertMessage` 提供原因摘要；`alertRim` 只为 critical 场景绘制细红弧。字号、边缘半径与描边来自基础定义。

`needle`、`liveArc`、`tachometer` 生成当前有效指示；静态刻度和危险范围保留在 `art.js`。冷却液高温范围以 110–120°C 的红色刻度表示，120 标签使用红色；柱内不保留独立红段。温度柱和综合页进度条由页面根据当前示例值生成。无数据时不绘制有效指示，静态危险刻度不代表当前报警。

### Action 与辅助控件

Action 属性包括位置、宽度、文字、动作名、`variant` 和 `disabled`。

- `variant`：`secondary`、`primary`、`ghost`、`danger`。
- 不可用状态独立于视觉变体，使用 `aria-disabled` 和 `tabindex=-1`，不响应点击或键盘。
- 按压、悬停与键盘焦点只改变颜色、描边或可见标记，不平移或缩放控件；反馈时长为 120ms，支持减少动画偏好。
- 音乐主键为 52px 圆形，辅助切歌图标保持 44px 点击区域。
- 开关同步显示拨片、ON / OFF 和 `aria-checked`。
- TPS / B.P 为整体切换区域；琥珀色与下划线共同标记当前项。

```js
U.actionButton({
  x: 240, y: 260, width: 240, label: 'CONFIRM', act: 'confirm',
  variant: 'primary', disabled: false
});
```

`roundButton`、`mediaButton`、`toggleControl` 和 `readoutControl` 是同一共享组件层的专用控件。动作仍由页面通过 `data-act` 接收，Enter / Space 与点击使用同一动作。

### Connection Row 与连接流程

`connectionRow({x,y,width,label,detail,status,act,selected})` 用于 15 / 17 页；默认宽 436、高 100 母版像素，整行点击。顶部为小标签，中部为设备名，底部可选状态；已存或连接项使用琥珀色与下划线，连接状态还须明确写出。右侧箭头表示可进入下一层，状态行不放独立小按钮。

15 页分别管理 OBD、手机和遥控；16 页仅为手机配对，17 页为仪表主动搜索与连接 OBD。适配器已连接与车辆数据就绪是不同状态；未点火时提示等待车辆。两种绑定的忘记确认相互独立；取消更换保留原有 OBD。演示进度在离开页面、打开确认框或切换场景后取消，不允许旧进度修改其他页面；场景选择器中的进度示例保持静态，点击操作才自动推进。亮度继续保留在 14 页。

### Gauge Shell 与页面组合

`shell()` 复用表盘底色、圆形边框和顶部定位标记；页面裁切和圆心遵循基础几何。底部不显示装饰署名，必要的断连信息由页面传入。

页面组合保留不同表现形式：01 / 02 / 04 / 12 的圆形主表、05 的偏心分区、06 / 07 的多项分区，以及 10 的同心坐标图。共用组件保障字体、读数和控件一致，构图继续适应各类数据。

10 页仅使用当前点与坐标刻度表达双轴方向，不显示底部 LAT / LON 标签或重复双轴数字。可选 G 值提醒触发时，仅使用虚线阈值圈与当前点强调，底部不显示 OVER、阈值数字或其他提醒文字。无数据时隐藏点与阈值圈。

## 修改与验证流程

修改基础定义后生成 CSS 和 JSON，再验证组件约束；完整导出命令同时生成界面资源：

```bash
cd ui-prototype
npm run export:foundations
npm test
npm run export
```

组件测试覆盖基础同步、44px 点击区域、圆边约束、不可用状态、Readout 的报警 / 断连语义、图形颜色绑定，以及所有页面在主要设置下能否渲染；新增场景测试覆盖断连优先级与图形抑制、多项异常排序、四轮定位、可选限值、独立心率和系统禁用状态；仍需浏览器验证实际排版。

16 页的反查结果与待修项目见 [DESIGN_AUDIT.md](DESIGN_AUDIT.md)。共享组件测试通过不能替代逐页验收。路景测试另外检查车速与频率的比例、静止 / 断连、透视范围和超速联动；动画仍需实际网页检查。

浏览器检查组件规范页的状态切换和控件，再检查受影响的表盘在 360 原尺寸下的文字、数字、单位、圆边和操作。有意调整视觉时同步导出 SVG、PNG 和总览，并更新中英文规范。
